## О версиях — честно

Версия проекта теперь согласована. **Единственный источник истины —
`pyproject.toml` → `[project] version` = `1.0.0`**, и то же значение стоит в
`src/antigona/__init__.py` → `__version__` (именно его печатает
`antigona --version`):

| Источник | Значение |
|---|---|
| `pyproject.toml` → `[project] version` | **1.0.0** |
| `src/antigona/__init__.py` → `__version__` (то, что печатает `antigona --version`) | **1.0.0** |
| `RELEASE_NOTES.md` (заголовок) | **v1.1.0 — 2026-07-28** (исторический документ) |

Расхождение между `pyproject.toml` и `__init__.py` устранено: распределение и
runtime сообщают один и тот же номер `1.0.0`. Заголовок `RELEASE_NOTES.md`
(версия v1.1.0, 2026-07-28) сохранён как **исторический** документ — это не
опубликованный релиз.

Ориентируйтесь на **hash коммита**, а не на номер версии: `git rev-parse HEAD`.
Единственный документ с датированными release notes — [`RELEASE_NOTES.md`](RELEASE_NOTES.md)
(v1.1.0, 2026-07-28); он сохранён как исторический.

### Added

- **Слой идентичности ОС для ограды рабочей области** — `e90e1b8`
  (`feat(fence)`): ограничение по `st_dev` + `st_ino` поверх обоих chokepoint'ов
  workspace, 40 security-тестов. Ранее содержательность определялась сравнением
  строк, что не ловит symlink-предков, регистр, Unicode NFC/NFD и bind-монтирования.
- **Content-addressed журнал событий** — `9062e11` (`feat(chain)`, волна G1b):
  цепочка событий + типизированные отказы блокировок; в `962202e` (G1c) имя
  головы привязано к байтам, обе блокировки внутри `try/finally`, отказ на
  present-but-blank HEAD.
- **Запись C11-вердиктов развёртывания в цепочку** — `be9fc3d` (`feat(evidence)`, G1d).
- **Runtime provenance guard, continuity record и инструменты восстановления** —
  `047873c` (`feat(consolidation)`).
- **CLI portrait v3** — `8acd435` (`feat(canonical)`), вместе с wave-11
  упрочнением approvals/путей и fd-безопасным teardown тестов.
- **Товарная обёртка (закоммичено в `ad69b13`, волна W7):**
  `install.sh` (установка одним кликом из чистого клона, fail-closed проверка
  Python ≥ 3.11, venv + `pip install -e`, проверка реальным импортом и запуском
  CLI, без `sudo` и без секретов), `SECURITY.md`, `CONTRIBUTING.md`,
  `ARCHITECTURE.md`, `CHANGELOG.md`, исправление раздела быстрого старта в
  `README.md`, `.env` добавлен в `.gitignore`. Конверт C11 этой волны —
  `5e271c7c` (HEAD).

### Security

- Закрыты P1-находки: grants approvals, принудительный `requires_approval`,
  единственный chokepoint `UnifiedToolExecutionLayer`, ограда workspace по пяти
  векторам (dotdot / symlink / absolute / normalize / encode) — темы коммитов
  `4d9184a`, `53396c5`, `cd948c4`, `e90e1b8`, `e5de4f4`.
- **Каждый** коммит, меняющий содержимое кандидата, сопровождается отдельным
  `chore(manifest): C11 envelope freeze for <sha>` — конверт неизменяемости
  пересчитывается по факту изменения, не «подгоняется».
- `.env` теперь в `.gitignore` (в этом рабочем дереве): ранее файл с ключами,
  положенный рядом с `pyproject.toml`, не был исключён из индекса.

### Известные ограничения (не выдаём за исправленное)

- Окно at-most-once при доставке: успешная отправка + падение до записи
  manifest → финальный ответ может потеряться. Описано в `RELEASE_NOTES.md`.
- Номера версий рассогласованы (см. таблицу выше).
- `start_antigona_stack.sh`, на который ссылался раздел быстрого старта README,
  в репозитории отсутствует (в дереве есть `start-all.sh` для Windows-контура,
  `start_gateway.sh` и `start_bot.sh` помечены как LEGACY/DORMANT). Раздел
  исправлен на `install.sh`; сами лаунчеры не переписаны.

## v1.1.0 — 2026-07-28

Полные release notes этого состояния — в [`RELEASE_NOTES.md`](RELEASE_NOTES.md).
Кратко: единый runtime-контур (три параллельных контура устранены, всё через
Gateway), жизненный цикл операции `progress → final → cleanup` с
`OperationStore`/`OperationPresenter`, закрытие P0 по безопасности (санитайз
входа и результата, SHA-256 в аргументах инструментов, whitelist-проекции API,
fail-closed переход в `DONE`), ужесточённый Gateway waiter. Остаточные риски —
там же (§«Остаточные риски»).
